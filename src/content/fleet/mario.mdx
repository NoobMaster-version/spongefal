## Mission

MARIO is the arm SRA students learn ROS2 on: a 3-DOF manipulator that exists
twice — as a Gazebo simulation and as physical hardware driven by an ESP32
running micro-ROS. When Gazebo Classic hit end-of-life, the whole teaching
stack was about to rot. My job: keep MARIO teachable.

## Build

- **Ported the simulation from Gazebo Classic to Gazebo Fortress** — the EOL
  migration touched the model description, plugins, and launch system
- Implemented a new teleop control system, built for workshop ease-of-use
- Improved the ESP32 ↔ micro-ROS hardware communication pipeline so the same
  commands drive both the sim and the physical arm

## Debrief

Modernizing someone else's working robot is a different discipline from
building your own: the constraint isn't "make it work," it's "don't break what
200 students depend on." MARIO now runs SRA's ROS2 workshops on current
tooling — the most durable result of anything I built that year.
