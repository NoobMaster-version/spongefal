## Mission

Connect three senses into one loop: **listen** (voice → command), **see**
(camera → object detection → 3D position), **act** (inverse kinematics →
pick-and-place with an Open Manipulator X arm in Gazebo).

## Build

- Voice commands parsed into target descriptions ("the red ball")
- Object detection and tracking locates the target in the camera frame
- 2D pixel coordinates converted to a 3D position estimate
- Forward and inverse kinematics drive the arm through the pick sequence
- Everything wired as ROS2 nodes — my first real contact with topics,
  services, and the discipline of modular robot software

## Debrief

This was my introduction to ROS2, and it became the template for every project
after it: MARIO's simulation work, the e-Yantra drone stack, the internship
navigation systems. Learning to think in nodes and topics — instead of one big
loop — was the single biggest jump in how I write robot software.
